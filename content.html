เรียนรู้ Prefixes

ค่อย ๆ สำรวจส่วนประกอบของคำ เข้าใจกลุ่มความหมายและกฎสำคัญ แล้วทดลองสร้างคำด้วยตัวเอง

Prefix ชิ้นเล็ก ๆ สามารถเปลี่ยนความหมายของคำได้มากกว่าที่คิด!
แผนที่บทเรียน
บทที่ 1

Prefix คืออะไร?

Prefix คือกลุ่มตัวอักษรที่เติมไว้ หน้าคำหลัก เพื่อเปลี่ยนหรือเพิ่มความหมายของคำเดิม ส่วนคำหลักก่อนเติม Prefix เรียกว่า Base Word

Prefix+Base Word=New Word
un + happy = unhappy
ไม่มีความสุข
re + write = rewrite
เขียนใหม่
pre + view = preview
ดูตัวอย่างล่วงหน้า
dis + agree = disagree
ไม่เห็นด้วย
mis + understand = misunderstand
เข้าใจผิด
จำง่าย ๆ

Prefix อยู่หน้า Base Word และมักมีความหมายเป็นของตัวเอง เมื่อรวมกันจึงช่วยให้เราเดาคำใหม่ได้

บทที่ 2

มองเห็นส่วนประกอบของคำ

แยกสีแต่ละส่วนเพื่อดูว่า Prefix เปลี่ยนความหมายของ Base Word อย่างไร

un+kind=unkind
Prefix

un-

หมายถึง “ไม่”

Base Word

kind

หมายถึง “ใจดี”

New Word

unkind

คำศัพท์ใหม่

New Meaning

ไม่ใจดี

ความหมายหลังเติม Prefix

ลองแยกคำ

re + use = reuse
ใช้ + อีกครั้ง = นำกลับมาใช้ใหม่
over + work = overwork
ทำงาน + มากเกินไป = ทำงานหนักเกินไป
sub + marine = submarine
ใต้ + ทะเล = เรือดำน้ำ
inter + school = interschool
ระหว่าง + โรงเรียน = ระหว่างโรงเรียน
บทที่ 3

กลุ่มความหมายของ Prefix

การจำเป็นกลุ่มช่วยให้เลือกใช้ Prefix ได้เร็วขึ้น และเดาคำที่ไม่คุ้นเคยได้ดีขึ้น

Negative / Opposite

un-, dis-, in-, im-, il-, ir-, anti-
ไม่ ตรงข้าม หรือ ต่อต้าน

Time / Order

pre-, post-, re-
ก่อน หลัง หรือ อีกครั้ง

Number

mono-, bi-, tri-, multi-, semi-
หนึ่ง สอง สาม หลาย หรือ ครึ่ง

Position / Direction

sub-, trans-, inter-
ใต้ ข้าม หรือ ระหว่าง

Degree / Amount

over-, under-, super-
มากเกินไป น้อยเกินไป หรือ เหนือกว่า

Relationship

co-, inter-
ร่วมกัน หรือ เชื่อมโยงระหว่างกัน

เทคนิคการเดาคำ

หา Prefix ก่อน → แยก Base Word → รวมความหมาย → ตรวจสอบกับบริบทของประโยค

บทที่ 4

กฎการเปลี่ยนรูป in-, im-, il-, ir-

Prefix กลุ่มนี้หมายถึง “ไม่” เหมือนกัน แต่อาจเปลี่ยนรูปให้พูดง่ายขึ้นตามตัวอักษรต้นของ Base Word

in-
inactive

ไม่กระตือรือร้น
ใช้กับคำทั่วไปหลายคำ

im-
impossible

เป็นไปไม่ได้
มักอยู่หน้า m, p, b

il-
illegal

ผิดกฎหมาย
อยู่หน้าคำที่ขึ้นต้นด้วย l

ir-
irregular

ไม่สม่ำเสมอ
อยู่หน้าคำที่ขึ้นต้นด้วย r

สรุปแบบง่าย

คิดว่าเป็น Prefix ตระกูลเดียวกันที่ “ปรับเสียงให้เข้ากับคำข้างหลัง” เช่น possible เริ่มด้วย p จึงใช้ impossible ไม่ใช่ inpossible

in + complete = incomplete
ไม่สมบูรณ์
im + mature = immature
ยังไม่เป็นผู้ใหญ่
il + logical = illogical
ไม่สมเหตุสมผล
ir + responsible = irresponsible
ไม่มีความรับผิดชอบ
