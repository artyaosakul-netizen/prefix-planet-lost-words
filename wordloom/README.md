# Wordloom — Prefix Studio

เว็บไซต์การเรียนรู้ Prefix ภาษาอังกฤษในรูปแบบ Editorial Minimal สำหรับนักเรียนระดับมัธยมศึกษา

## จุดเด่น

- บทเรียน 6 ชุด ครอบคลุม Prefix สำคัญ 24+ รูป
- คลังคำและ Flashcard ค้นหา/กรอง/สุ่มได้
- แบบฝึกสั้น 10 คำ
- แบบทดสอบจริง 60 ข้อ แบ่งชุดละ 10 ข้อ
- ระบบจับเวลา 60 นาที ทำเครื่องหมายข้อ และ Navigator 1–60
- บันทึกข้อมูล คำตอบ เวลา คะแนน และประวัติ 5 ครั้งด้วย localStorage
- เฉลยละเอียดพร้อม Prefix, Base Word, New Word และคำแปล
- พิมพ์ผล A4 และดาวน์โหลด CSV
- รองรับโทรศัพท์ แท็บเล็ต คอมพิวเตอร์ Keyboard และ Screen Reader

## เปิดใช้งาน

เปิด `index.html` ได้โดยตรง หรือใช้เว็บเซิร์ฟเวอร์แบบ Static ใด ๆ เช่น GitHub Pages

## แก้ไขเนื้อหา

- คำถามและเฉลยทั้งหมดอยู่ใน `questions.js`
- สีและรูปแบบอยู่ใน `styles.css`
- ระบบโต้ตอบอยู่ใน `app.js`

เว็บไซต์ใช้ HTML5, CSS3 และ Vanilla JavaScript โดยไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม
